# resumo-dos-candidatos
Plataforma pública (web) que, para as Eleições Gerais 2026 (1º turno em 04/10/2026), agrega por candidato:   Propostas divulgadas na candidatura. Histórico de atuação pública (votos, proposições, faltas/presença, gastos, ações) — somente para candidatos em reeleição que já exercem mandato.
